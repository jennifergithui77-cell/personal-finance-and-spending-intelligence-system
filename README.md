# Personal Finance and Spending Intelligence System

## Project Overview

The Personal Finance and Spending Intelligence System is a data analytics project designed to help users understand their financial activities through transaction analysis, spending patterns, income tracking and interactive visualisations.

The project uses synthetic financial transaction data to demonstrate how data analytics and business intelligence tools can transform raw financial records into meaningful insights.

## Project Objectives

- Analyse income and expenditure patterns.
- Identify major spending categories.
- Monitor financial trends over time.
- Compare financial activities across different users.
- Present financial insights through an interactive Power BI dashboard.

## Technologies Used

- **Power BI** – Interactive dashboard development and visualisation.
- **Python** – Data processing and analysis.
- **Pandas** – Data manipulation and analysis.
- **Jupyter Notebook** – Exploratory data analysis.
- **Git and GitHub** – Version control and project hosting.

## Dashboard Pages

The Power BI dashboard contains four main pages.

### 1. Personal Finance Overview
Provides a summary of income, expenses and monthly financial activity.


### 2. Transaction Details
Displays individual financial transactions with filtering options.



### 3. Financial Trends & Analysis
Explores financial performance and changes in income, expenses and net financial position over time.


### 4. User Insights
Compares financial activities and spending patterns across different users.


## Dataset

The project uses synthetic financial transaction data containing records for 10 fictional users.

The dataset includes:
- Transaction Date
- Transaction Description
- Category
- Amount
- Transaction Type
- User ID

Transaction types include Income, Expense and Transfer.

**Note:** The dataset is synthetic and does not contain real personal financial records.
